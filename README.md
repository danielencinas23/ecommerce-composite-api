# E-Commerce Gateway & Dashboard — Composite API

Práctica de **Desarrollo Web Integral – Unidad 3** (UTCH, Desarrollo y Gestión de Software).

Composite API (API agregadora) que unifica en una sola respuesta la información de:

1. Microservicio de Catálogo de Productos (API propia).
2. Microservicio de Inventario y Almacén (API propia).
3. API externa de tipo de cambio USD → MXN (Frankfurter).

## Ejecución

```bash
npm install
npm start
```
